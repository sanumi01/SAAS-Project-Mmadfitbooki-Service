# MMAD Cloud & Data Freelance Platform - Mobile Application

This is the mobile application for the MMAD Cloud & Data Freelance Platform, designed to facilitate interactions between freelancers and clients. The application allows freelancers to register, showcase their services, and enables clients to submit enquiries.

## Features

- **Freelancer Registration**: Freelancers can create profiles and list their services.
- **Service Showcase**: A dedicated section for freelancers to display their offerings.
- **Client Enquiries**: Clients can submit enquiries directly through the app.
- **Dashboard**: A user-friendly interface for navigating the app and accessing features.

## Technology Stack

- **React Native**: For building the mobile application.
- **TypeScript**: For type safety and better development experience.
- **AWS S3**: For secure storage of user data and service information.

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the mobile directory:
   ```
   cd mmad-freelance-platform/mobile
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Run the application:
   ```
   npm start
   ```

## Usage

- **Freelancers**: Register and create a profile to start showcasing your services.
- **Clients**: Browse through available freelancers and submit enquiries for services.

## Commission Model

The platform operates on a 10% commission model for all transactions facilitated through the app.
